# FrameDock TV — phone

The phone companion for FrameDock TV, a custom launcher for a Samsung Tizen TV.
Scan the QR code on the TV (FrameDock TV → Send from phone): this page then shows the same home screen,
channels and playlists, and opens them on the TV.

The TV's secret channel arrives in the QR link after `#` and is stored only on the phone; it is never part of this repository.
